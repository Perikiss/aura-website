# AURA Skincare — Final Project

## Pages
- `index.html` — Home, brand introduction, AURA Secret Gift, FAQ.
- `about.html` — About the brand and team.
- `collection.html` — Product cards, filtering, ratings and jQuery search.
- `contact.html` — Contact form with custom JavaScript validation.
- `account.html` — Sign Up and Log In tabs on one page.
- `profile.html` — Profile after a successful demo login.
- `routine.html` — Skin type and goal selector, AM/PM routine, daily tracker and Open Beauty Facts API search.

## Technologies
HTML5, CSS3 (Flexbox and Grid), JavaScript, jQuery 3.7.1, Fetch API, localStorage. No CSS framework.

## Features preserved from Assignments 5–6
Day/night mode, language selector, background color changer, local time, sound, read-more, FAQ, Secret Gift, Magic Mirror product cards, loader, product filtering and ratings, search/autocomplete/highlighting, scroll progress, counters, toast messages, clipboard copy and lazy loading.

## Run locally
Open `index.html` in a browser. For best API behavior, run a local server (for example VS Code Live Server) or deploy to GitHub Pages.

## API
The Skin Routine page uses the Open Beauty Facts public cosmetics database: https://world.openbeautyfacts.org/ . Results are community-contributed and may be incomplete.

## Demo authentication notice
This is a front-end academic simulation. The demo stores a password in browser `localStorage`, which is NOT secure. Never use a real password or real personal data. A production application must use a secure backend and hashed passwords.

## Deployment
Push the complete `aura-website` folder to the existing GitHub repository `Perikiss/aura-website`. Enable GitHub Pages from the repository settings (Deploy from branch, `main`, `/root`). Check every page and image after deployment.
